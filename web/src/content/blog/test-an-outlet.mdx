You don&rsquo;t need a multimeter to figure out whether an outlet is dead, polarity-reversed, or actively dangerous. Here&rsquo;s the routine I run before pulling the cover.

## Look first

- **Discoloration** around the slots? Heat damage. Stop using it.
- **Loose face**? The outlet body is no longer secured — kids can pull it out.
- **Smell of melted plastic**? Don&rsquo;t plug anything in. Switch the breaker off and call.

## Plug a charger

Any USB charger with an LED. Three things can happen:

| Behavior | Likely cause |
| --- | --- |
| LED on, charges normally | Outlet is fine |
| LED on, plug feels loose | Worn contacts — replacement, not repair |
| Nothing | Dead circuit, broken outlet, or tripped breaker |

## If it&rsquo;s dead

Check the panel. If the breaker is on and other outlets on the same circuit are dead too, the issue is upstream — usually the first outlet on the daisy chain has a failed back-stab or a loose terminal.

## When to stop

Three rules:

1. **Don&rsquo;t test with your fingers.**
2. **Don&rsquo;t open an outlet while the breaker is on.**
3. **Don&rsquo;t replace it if the wire jacket is brittle or discolored.** That&rsquo;s a wider problem.
